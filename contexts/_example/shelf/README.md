# Shelf

The current reference for this context.

Files here are what every project is allowed to treat as true. A review or
a rewrite does not happen in place. Start a project, work on a copy, and
publish back only when you mean to replace the current text.

Publishing is not saving. A newer draft in a project does not become the
reference because it is newer. What a publish replaces is kept in
`.history/`, by its name and the time, and is no longer current.

```
shelf/
  classification.md    # the regulation as it stands
```

This directory ships with no documents.
