# Principles

Rules of engagement for this project. Breaking one means the project was
done wrong, even if the document shipped.

- Do not present a draft as the current reference. The shelf is current.
  This folder is a proposal.
- Do not edit another project's file, or a shelf file, unless this specific
  change was approved. Approval covers that file, once. It does not unlock
  the rest of the folder or the rest of the session.
- A conflict you notice is written in this project. Noticing it does not
  approve the edit.
- Do not invent evidence the source does not contain.

If skipping it would merely change the approach, it was an intent. Move it.
