# Example context

A context is a vessel of knowledge. It is not a place where work happens.

This directory is a shape, not a sample of anyone's work. Copy it and
replace `_example` with your own world. Do not put client names, private
documents, or credentials in a public checkout of this repository.

## What lives here

- `shelf/` is the current reference. Other projects treat these files as
  what is true now. They change only when a project publishes.
- `projects/` holds the efforts inside this world. Each project is its own
  desk, with its own folder, intents, and principles.
- `dropbox/` is intake for material that belongs to the world but has not
  been placed yet. A regulation library you want every project to read
  lands on the shelf, not in a project.

Nothing in a context is actionable. There are no intents and no principles
here. To do anything, open a project.

## What an index may see

A helper index, if you build one, reads this whole directory: the shelf and
every project folder, including drafts. It is rebuildable from these files.
Deleting it loses nothing. It never includes another context.

Asking what is currently true cites the shelf. Asking what a proposal would
imply may read a sibling project's draft, and must say which is which.
A finding stays in the project that noticed it.
