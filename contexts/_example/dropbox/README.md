# Context dropbox

Intake for material that belongs to the world, not yet to an effort.

Three exits, and no fourth:

1. **Leave it outside and index it.** The file stays where it arrived.
   The context records the path or the link.
2. **Keep it as a context source.** It belongs on the shelf, or beside it,
   and every project may read it. It is not editable from a project.
3. **Extract the text onto the shelf.** A PDF or a page becomes a readable
   note. The original stays outside, or sits next to the note. The note is
   the reference only after you put it on the shelf on purpose.

Filing something here is not acting on the context. Deciding what it means
happens after a project takes a copy.
