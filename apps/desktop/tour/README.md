# Mate tour

You are looking at a *context*. It is a plain folder, and everything in it is a file you could open
in any editor. Mate shows the folder as a desk. It keeps no database, and nothing here needs a server.

- `shelf/` holds what is true now.
- `projects/` holds the efforts. Each one is its own desk. This context has one, `tour`.
- Hidden folders such as `.mate/` hold what Mate keeps for you, like private comments. The
  index in `.indexes/` can be deleted at any time and is built again.

Open the project **tour** in the rail, and start with `start-here.md`. Each page is short, and
each asks you to try one thing.

When you have finished, delete this folder. Nothing else on your computer changed.
