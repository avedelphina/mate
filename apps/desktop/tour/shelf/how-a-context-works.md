# How a context works

This is a document of the shelf. The shelf is what is true now, and every project of the context
reads it as the reference. It changes only when a person publishes a document to it. Mate keeps the
text it replaces in `shelf/.history/`.

A proposal is not on the shelf. It is a document in a project, and it stays a proposal until
someone publishes it. That is the one rule the rest follows. An agent can write a proposal. Only you
can make it true.
