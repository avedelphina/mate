# Links and the graph

Write `[[name]]` to point at another document, as Obsidian does. It means the file of that name, in
this project, then on the shelf, then in any other project.

- `[[name|words]]` shows other words.
- `[[name#Heading]]` opens the file and scrolls to the heading.
- A name that no file has is shown dashed, like this one: [[a-document-nobody-wrote]].

## Try it

- Press [[start-here]]. It opens.
- Press **Linked from…** in this page's bar. It lists the documents that point here.
- Press **Graph** in the rail. Every document that links to another is a point, and a press opens it.
  The shelf is green and proposals are dark.
- Right-click `sources.md` in the tree, and choose **Rename…**. If documents link to it, a dialog
  asks whether the links follow.
