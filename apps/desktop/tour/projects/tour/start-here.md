# Start here

Mate is a desk for a body of work. You write and read documents, you leave review comments, and an
agent can help when you invite one. The files are the product. If you delete Mate, your documents
stay.

Work through these in order. Each takes a minute.

1. [[read-and-comment]]: select a sentence and comment on it.
2. [[drafts-and-the-shelf]]: what a proposal is, and how one becomes true.
3. [[fields-and-tags]]: the front matter of a document, as a row you can edit.
4. [[links-and-the-graph]]: documents that point at each other.
5. [[sources]]: bring in a file that is not markdown.
6. [[invite-an-agent]]: let an agent propose, and decide what stays.
7. [[search-references-and-trust]]: find things, point at what is outside, and what Mate may run.

The tasks pane in the margin lists the same things to tick. The shelf has one document to read
too: [[how-a-context-works]].
