# Sources

Not everything is markdown. A PDF, a Word file, a page or a table can be brought in and read as text.

## Try it

1. Press `material/prices.csv` in the tree. It is a table, so Mate shows a card, not a page.
2. **Open as a table** shows the rows and columns. Type in the box under a column to keep only the
   rows that hold those words: `=exact` for exactly them, `!words` for rows without them. Press a
   heading to put the rows in order. Press a cell of a CSV to change it, and **Save** writes the
   file back as it was written. A workbook from Excel is shown, not changed.
3. **Make a document from its text** takes the text out with no agent and writes it as a new
   document, with where it came from at the top.
4. **Save its text beside the file** writes the same text as a markdown file next to the original.
   Use it when the text should stay with its neighbours.

On a Mac, Mate reads PDF and Word files with the system's own tools, and reads a scan off its
picture.

## The dropbox

`dropbox/` is intake. Open `dropbox/supplier-note.md`. A file there leaves by an exit you choose.
It can stay where it is with a note that says where, or be pulled into the project. Nothing
leaves the dropbox by itself. You can also drop a file on the window, or use **Add a Source…** in
the project's menu.
