# Invite an agent

Mate does not need an agent. When you want one, you invite it into a project. It can be Claude Code,
Codex, Hermes, Kimi or any MCP client. Choose in **Settings**.

## What it may do

- It reads the whole context, and says which source is the shelf and which is a proposal.
- It plans first. It writes only after you approve the plan.
- It writes in its own project. A change anywhere else is put back, and held until you approve
  that one file. A change it made can be reverted.
- It can show you what it gathered in a **pane**: a markdown file beside the page. Look at the
  **tasks** tab in the margin. Tick a task and the file changes.
- It cannot publish, and it cannot commit. Those stay yours.

## Try it

Open the **Chat** tab in the margin, and say what you want done to this project. Read its plan
before you approve it. If you have no agent set up yet, read this page and carry on.

You can give a session a folder to work in, or let it work on a copy of a repository, so that two
agents do not meet. [[search-references-and-trust]] says what an agent is allowed to run.
