# Tasks

A pane is a markdown file that an agent writes to show you something. This one came with the tour.
Tick a task and the file changes. In a real project an agent fills a pane from a tracker it can
reach, and says where each line came from.

## The tour

- [ ] Comment on a sentence in `read-and-comment.md`
- [ ] Look at `drafts-and-the-shelf.md` and press **Publish…**, then cancel
- [ ] Change a field in `fields-and-tags.md`
- [ ] Press **Graph** in the rail
- [ ] Take the text out of `material/prices.csv`
- [ ] Read the plan of an agent before you approve it

Each of these is a button too, if an agent is set up:

[Tell me what to try next](say:)
